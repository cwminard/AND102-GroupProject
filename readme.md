## Overview
Flower Disocovery is an app made for people who look at the world and say, "What is this?"

Flower Discovery enables you to find the associated information with plants all around the world and assists in plant identification!

### Description

Flower Discovery has the power to transform your world, whether you're a botanist or just a regular person, curious about the plants and flowers that surroound you. This application will give you the answes to the questions you have about different species of plants and flowers.

### App Evaluation
**Category**: Education / Utility

**Mobile**: Mobile-first experience relying heavily on the camera for real-time flower identification.

**Story**: Users frequently encounter flowers they cannot name. This app provides instant answers, symbolic meanings, and growing guides, creating a fun and educational experience.

**Market**: Gardeners, florists, students, hikers, nature lovers, and anyone interested in flowers or gifting.

**Habit**: Users return whenever they encounter new flowers, plan gardens, or build their personal flower collections.

**Scope**: Users should be able to login/signup, retrieve information about plant

## Product Spec

### 1. User Features (Required and Optional)

**Required Features**

1. Signup/Login: user should be able to have secure access to the application.
2. Plant Discovery: user should be able to find new plants and flowers
3. Favorites: user should be able to log a type of plant or flower as a favorite, where it will move to a dedicated section.

**Optional Features**

1. Boquet Builder: user can build a custom bouquet using their favorites
2. Flower of the Day: randomly generated flower displays when they open app
3. Photocapture: user should be able to capture a photo to search for a plant

🌸 Description

Flower Discovery App is a mobile application that allows users to identify flowers by taking a photo with their phone. The app returns the flower’s name, symbolism/meaning, growing conditions, and related flowers. Users can save identified flowers, browse their personal collection, and explore additional flower facts.

📊 App Evaluation

Category: Education / Utility
Mobile: Mobile-first experience relying heavily on the camera for real-time flower identification.
Story: Users frequently encounter flowers they cannot name. This app provides instant answers, symbolic meanings, and growing guides, creating a fun and educational experience.
Market: Gardeners, florists, students, hikers, nature lovers, and anyone interested in flowers or gifting.
Habit: Users return whenever they encounter new flowers, plan gardens, or build their personal flower collections.
Scope:
V1: Photo identification + flower info page
V2: Saved flowers + care recommendations
V3: Bouquet builder + shareable digital cards

Product Spec

🧩 User Features (Required & Optional)
Required Features (MVP)
User can take a photo of a flower using the app’s built-in camera.
App identifies the flower and displays: name, symbolism, and basic care details.
User can save identified flowers into a personal collection.
User can view a gallery of all previously saved flowers.
Optional Features (Nice-to-Haves)
Bouquet Creator: combine multiple flowers to generate bouquet suggestions.
“Flower of the Day” notification with meaning and fun facts.
Social sharing: export identified flower cards to Instagram, Messages, etc.
Search database to explore flowers without taking a picture.
Offline identification (downloadable model).

📱 Screen Archetypes

Camera Screen
Take a photo of a flower
Tap to capture
After capture → navigate to Identification Result screen
Identification Result Screen
Displays name, symbolism, care details
Button to “Save to Collection”
Option to retake picture

Optional: “See Related Flowers”

Saved Collection Screen (Gallery)
Shows user’s saved flowers in a grid
Tap on a flower → open Detail screen

Flower Detail Screen
Displays full information about a saved flower
Symbolism
Growing conditions
Add notes (optional feature)

5. Profile / Settings Screen (Optional)

App info
